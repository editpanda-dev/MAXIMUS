# Jang Han-byeol Character Variants

기본 장한별 원화를 캐릭터·스타일 기준으로 사용해 생성한 파생 PNG 자산이다. 모든 파일은 1254 × 1254 RGBA, 투명 배경이다.

## Assets

- `jang-han-byeol-tempura-udon.png`: 바닥에 앉아 튀김우동을 먹는 장한별
- `jang-han-byeol-poodle-suit.png`: 푸들 후드·인형탈을 입은 장한별
- `jang-han-byeol-playing-seulang-i.png`: 슬랑이를 양손으로 조물조물 만지는 장한별
- `jang-han-byeol-pogo-stick.png`: 스카이콩콩을 타는 장한별

## Generation references

- Character identity and line style: `../../reference/jang-han-byeol-base.png`
- Seulang-i shape and material: `../../reference/seulang-i-reference.png`

## Shared generation constraints

- 기본형의 얼굴, 반쯤 감긴 눈, 옆머리 묶음, 느슨한 티셔츠, 조거 팬츠, 운동화, 흑백 선화 유지
- 텍스트, UI, 로고, 워터마크, 배경, 추가 캐릭터 제외
- 슬랑이만 식별을 위한 연한 크림색 사용
