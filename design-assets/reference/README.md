# Design Asset Archive

장한별 키우기의 제품 설계와 Figma 생성 프롬프트에서 참조할 원본 디자인 자산이다.

## Assets

- `jang-al-byeol-egg.png`: 장알별 기본 원화
- `jang-han-byeol-base.png`: 장한별 기본 캐릭터 원화
- `jang-han-byeol-drag-motion-guide.png`: Drag & Drop 허우적 모션 8프레임 가이드

## Usage notes

- 원본 자산은 덞어쓰지 않는다.
- 파생 자산은 별도 폴더에서 관리한다.
- 프로토타입의 캐릭터 비율과 허우적 리듬은 본 가이드를 우선 참조한다.
